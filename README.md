## ✨ Overview

**RAAHI (راہگیر)** is an atmospheric, aesthetic web application designed for relaxation, focus, and inner peace. Featuring a stunning oil painting background of a hiker sitting on a mountain cliff at golden sunset, dynamic ambient particle effects, auto-rotating Urdu wisdom cards, and a deluxe floating music player powered by YouTube playlists.

---

## 🚀 Features

- **🎨 Fullscreen Sunset Mountain Background**: Rich, high-resolution oil painting visuals with warm atmospheric lighting.
- **🎵 Deluxe Floating Music Player**: Seamless YouTube playlist streaming with real-time video title and artist metadata extraction, interactive progress bar, volume controls, and keyboard shortcuts (`Space` to toggle, `Right Arrow` for next, `M` for mute).
- **📜 Auto-Rotating Urdu Quote Cards**:
  - **Healing Mountain Quotes** (*روحانی سکون*): Peaceful reflections that change automatically every 5 seconds with a smooth timer bar.
  - **Wanderer's Wisdom** (*دانا باتیں*): Lighthearted thoughts to bring a smile.
- **✨ Ambient Floating Particles**: Dynamic Canvas particle system simulating mountain dust and glowing embers.
- **📱 100% Fully Responsive**: Optimized for desktop, laptop, tablet, and mobile viewports.
- **🔖 Custom Mountain Favicon**: Embedded SVG tab icon featuring glowing mountain peaks.

## 🛠️ Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Audio API**: YouTube IFrame Player API

## 💻 Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) (v18 or higher) installed.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Sagheer1122/Raahii.git
   cd Raahii
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to view the app.

---

## 📦 Production Build

To build the project for production:

```bash
npm run build
npm run start
```
